개인정보 처리방침

시행일: 2026년 11월 24일 · 대상: Alfred AI - Handsfree System iPhone 앱, Handsfree AI Helper(Mac) · 운영: SeoulFactory

1. 수집하는 정보

Alfred AI - Handsfree System는 회원가입이 없고 자체 서버를 운영하지 않습니다. 녹음 오디오, 받아쓴 텍스트, AI 요약, 설정, 사용자가 입력한 API 키는 사용자 기기 안에만 저장됩니다. 개발자는 이 정보에 접근할 수 없습니다.

2. 제3자 AI 서비스로의 전송

사용자가 AI 기능을 처음 쓸 때 앱 안에서 동의를 받은 후에만, 아래 데이터를 사용자 본인의 API 키로 해당 회사에 직접 전송합니다.

  • Anthropic (Claude): 받아쓴 텍스트, 녹음 전사, 질문 — 대화 답변, 다듬기, 요약, 번역, 화자 구분, 검색
  • OpenAI: 받아쓴 텍스트, 질문 — 대화 답변 / 말하기·녹음 오디오 — 음성 전사(설정에서 ChatGPT 받아쓰기를 선택한 경우)
  • Apple 음성 인식: 아이폰 내장 음성 인식을 쓰는 경우 음성이 Apple에서 처리될 수 있습니다.

각 회사의 데이터 처리는 해당 회사의 개인정보 처리방침을 따릅니다.

3. 노트북으로 보내기와 마우스로 말하기 (Handsfree AI Helper)

노트북으로 보내면 받아쓴 텍스트가 같은 Wi-Fi 안에서 사용자의 Mac으로 직접 전송되며 인터넷을 거치지 않습니다. Mac 도우미는 연결된 아이폰을 구분하기 위한 임의의 토큰만 Mac에 저장하고, 받은 텍스트는 선택한 앱의 입력창에 붙여넣은 뒤 보관하지 않습니다. “마우스로 말하기”를 쓰면 더블클릭한 마우스 버튼을 누르고 있는 동안만 Mac 마이크로 듣고, Mac의 Apple 음성 인식으로 받아쓴 뒤 커서 위치에 붙여넣습니다. 오디오와 텍스트는 저장하지 않습니다. 문제 해결용 기록(~/Library/Logs/HandsfreeAIHelper.log)에는 시각과 글자 수만 남고 내용은 남지 않습니다.

4. 권한

  • 아이폰: 마이크(녹음·받아쓰기), 음성 인식(내장 받아쓰기), 로컬 네트워크(노트북 찾기·전송)
  • Mac: 손쉬운 사용(입력창에 붙여넣기·전송, 마우스 버튼 감지), 마이크·음성 인식(마우스로 말하기)

화면 기록 권한, 위치, 연락처, 광고 식별자는 사용하지 않으며 추적(트래킹)을 하지 않습니다.

5. 사용자의 권리

아이폰 앱의 설정 → 개인정보에서 AI 전송 동의를 철회하거나 모든 데이터를 즉시 삭제할 수 있습니다. Mac 도우미 창의 “모두 연결 해제”로 연결 정보를 지울 수 있습니다. 앱을 삭제하면 기기 안의 데이터도 함께 삭제됩니다.

6. 아동

이 서비스는 만 14세 미만 아동을 대상으로 하지 않습니다.
