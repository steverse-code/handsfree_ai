문제가 있거나 제안이 있으면 GitHub 문의 게시판에 남겨 주세요. 사용하는 아이폰·Mac 기종과 iOS·macOS 버전을 함께 적어 주시면 빨리 도와드릴 수 있어요.

자주 묻는 질문

노트북을 찾지 못해요

① 아이폰과 노트북이 같은 Wi-Fi인지 ② Mac에서 ‘VoiceBridge 도우미’가 켜져 있는지(Dock 아이콘) ③ 아이폰 설정 → VoiceBridge → 로컬 네트워크가 켜져 있는지 확인하세요. 회사·학교 Wi-Fi는 기기 간 연결을 막는 경우가 있어요.

보냈는데 Claude 입력창에 글이 안 들어가요

시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 ‘VoiceBridge 도우미’가 켜져 있는지 확인하세요. Mac 화면이 잠겨 있으면 입력할 수 없어요. 도우미 창의 “마지막:” 줄에 실패 이유가 표시됩니다.

입력만 하고 전송은 직접 하고 싶어요

말하기 탭에서 “보내기 누르면 노트북에서 바로 전송”을 끄세요. 그러면 입력창에만 들어가고, ⏎ 버튼이나 노트북에서 직접 전송할 수 있어요.

화면을 끄면 녹음이 멈추나요?

아니요. 녹음노트는 화면을 꺼도 계속 녹음되고, 잠금화면에서 시간·하이라이트·정지를 할 수 있어요. 제어 센터에 “VoiceBridge 녹음”을 추가하면 앱을 열지 않고 시작할 수 있어요.

AI 요약에 API 키가 필요한가요?

네. 앱 안에서 AI 답변·요약을 받으려면 Anthropic(Claude) 또는 OpenAI API 키가 필요해요. 노트북 Claude로 보내기, 녹음, 기기 내 받아쓰기는 API 키 없이 쓸 수 있어요.

Mac 도우미를 지우려면?

도우미를 종료하고 응용 프로그램 폴더에서 휴지통으로 옮기면 됩니다.
